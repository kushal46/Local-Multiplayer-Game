<h1>Local Multiplayer Pong Game</h1>

This is a classic Pong game where two players can play against each other locally on the same keyboard. The game uses basic HTML, CSS, and JavaScript for rendering the game elements and handling the game logic.


<h2>Features</h2>

Simple and clean UI
Real-time ball and paddle movements
Collision detection between ball and paddles
Basic keyboard controls for both players

<h2>How to Play</h2>
Player 1 controls:

Move up: W
Move down: S
Player 2 controls:

Move up: Arrow Up
Move down: Arrow Down
The objective is to prevent the ball from passing your paddle and score by getting the ball past your opponent's paddle.
